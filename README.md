# 最小发布入口

已准备好可直接用于静态托管的目录：

- `publish/index.html`
- `publish/decks/laozhou-magazine/index.html`

## 推荐发布方式

### GitHub Pages
把 `publish/` 目录内容推到一个 Pages 仓库根目录，或推到任意仓库后在 Settings → Pages 里选择对应分支/目录。

### 目录说明
- `index.html`：总入口
- `decks/laozhou-magazine/index.html`：昨天那份杂志风网页 PPT

## 当前状态
这是纯静态页面，不依赖后端，可直接挂到 GitHub Pages、Cloudflare Pages、Netlify、Vercel 等任意静态托管。
